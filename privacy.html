Privacy policy

Last updated: 2026-11-10

Dagfinn Productions is one person publishing free, open source apps and short videos about them. This page explains what data is handled.

This website

This website is static. It has no accounts, no forms, no cookies, no analytics and no advertising. It is hosted on GitHub Pages, and GitHub may log visits according to its own privacy statement.

Media assistant and YouTube API Services

I use a small personal tool (the "media assistant") to publish my own videos to my own accounts, including my own YouTube channel. It is not offered to other people, and no one else is asked to sign in to it.

For YouTube, the tool uses YouTube API Services (YouTube Data API) to upload videos to my own channel. It does this after I have signed in with my own Google account and granted the upload permission.

  • What it accesses: only the permission to upload videos to my own channel.
  • What it stores: an OAuth token for my own account, kept in a protected file on my own home server. Nothing is stored in any cloud service run by me.
  • What it does not do: it does not collect, store or share data about viewers, subscribers or other YouTube users, and it does not sell or share data with third parties.
  • Revoking access: I can revoke the tool's access at any time in my Google Account at security.google.com/settings/security/permissions.

By using YouTube you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data retention and deletion

The media assistant stores one thing: my own OAuth refresh token, in a protected file on my own home server. It is kept until I revoke access or delete it. Revoking access in my Google Account (see above) makes the token unusable, and I delete the file when I stop using the tool. Because the tool does not collect data about viewers, subscribers or other users, there is no other data to delete. If you believe this tool holds data about you, contact me (see below) and I will delete it.

The apps

  • RedScreen does not connect to the internet. Its settings are stored only on your own PC.
  • Bindy sends screenshots and text to Anthropic through your own Claude login when you use it. See its privacy page for exactly what is sent and stored.
